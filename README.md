# Room Mockup

Upload a photo of your room and mock it up with **real, buyable products** pulled from many stores
(Amazon, Wayfair, Facebook Marketplace, and more) instead of a single retailer's catalog.

Status: early prototype. This commit is the bare Next.js (App Router) + TypeScript scaffold.

## Run locally

```bash
git clone https://github.com/kellanmreagan/room-mockup.git
cd room-mockup
npm install
npm run dev
# open http://localhost:3000
```
